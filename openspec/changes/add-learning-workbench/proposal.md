# 提案：稳定化中文学习工作台

## Why

当前分支的 `cdbd47e` 已经把每日技术简报升级为 8 篇独立学习笔记和 1 篇索引，并具备中文目录、中文标签、原始链接、源码读取、60 天去重与 systemd 定时运行。剩余问题不是重新实现采集器，而是让这条链路可以长期稳定运行：同一内容可能通过 Trending、Search、Release 或多个 RSS 入口重复进入候选；失败只能从临时文件和 journal 中拼接判断；现有测试没有直接证明独立 Markdown、标签、索引、去重和失败恢复；旧的 GitHub Trending 与 AI Frontier 定时器在切换后仍可能继续写入旧式聚合笔记。

因此，本变更把已有采集器收敛为单一、可验证、可审计、可安全切换的中文学习资料流水线，确保每天实际得到 6–10 篇高质量且不重复的独立学习笔记，而不是再次增加一套采集实现。

## What Changes

- 保留现有 `learning-library-collector.mjs` 作为唯一的新学习资料流水线，不重写已经完成的来源采集、源码读取和 Markdown 渲染能力。
- 为仓库、文章和社区讨论建立稳定的规范化内容标识，阻止同一材料通过不同来源或不同 URL 形式重复入选。
- 将每日目标保持为 8 篇（位于用户要求的 6–10 篇范围内）；候选质量或来源结构不满足要求时明确失败，不使用低质量内容凑数。
- 持久化不含密钥的每日运行记录，包含阶段、开始与结束时间、候选与入选数量、来源警告、失败原因、重试状态和最终写入数量。
- 增加对独立中文 Markdown、Front Matter、中文标签、原始链接、每日索引、幂等重试、跨来源去重和失败记录的自动化测试。
- 提供可重复执行的 systemd 切换步骤：更新统一采集服务，停用旧的 GitHub Trending 与 AI Frontier 定时器，保留历史笔记但不再产生旧式聚合内容。
- 更新运行手册，说明手动执行、状态检查、失败重试、旧任务切换和回滚方法。

## Scope

### In Scope

- 每天 8 篇独立中文学习笔记和 1 篇精简导航索引。
- GitHub、技术文章、研究论文与技术社区候选的高质量筛选。
- 中文目录、中文分层标签、原始链接、采集日期与来源信息。
- 同批次及 60 天窗口内的稳定去重和 MCP 写入幂等。
- 本地状态、systemd journal 和运行记录共同构成的失败诊断证据。
- Git 管理的 systemd 切换、验证与回滚步骤。

### Out of Scope

- Inkstone 数据库表、公共 API 或笔记编辑器的改造。
- 新增学习看板、收藏、阅读进度、复习提醒或语义搜索界面。
- 第二批的更多 RSS/论坛来源、可视化来源配置和学习状态管理。
- MindFS 功能扩展及 MindFS 与 Inkstone 的双向联动。
- 自动删除已经生成的旧笔记，或未经确认直接部署到生产 VPS。

## Impact

- 主要影响 `scripts/learning-library-collector.mjs`、对应 Node 测试、systemd 单元、采集器运行文档和部署切换脚本。
- 不改变 Inkstone 浏览器 API、MCP 协议、数据库结构或现有用户笔记。
- 生产切换会改变启用的定时器集合，但不会删除旧服务文件、旧状态目录或历史笔记，因而可以回滚。

## Proof of Completion

- 自动化测试证明默认每天选择 8 篇，数量落在 6–10 范围内，来源比例与主题下限符合约束。
- 固定夹具证明同一仓库或文章经不同入口、URL 参数和尾斜杠出现时只保留一项，60 天内不会再次入选。
- 固定夹具证明每篇输出是独立中文 Markdown，含完整 Front Matter、中文标签、原始链接和学习章节；每日索引只做导航并链接到全部独立笔记。
- 故障注入测试证明采集、模型生成或 MCP 写入失败会留下明确运行记录，重试复用持久化载荷且不重复创建笔记。
- 本地全量测试与 VPS 构建通过；切换手册可证明统一定时器启用、旧定时器停用，并能在不删除数据的情况下回滚。
